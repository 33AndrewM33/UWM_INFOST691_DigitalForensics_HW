# INFOST 691 - Special Topics in Information Science: Digital Forensics
**University of Wisconsin-Milwaukee**
A collection of homework assignments completed as part of INFOST 691, a digital forensics course at UW-Milwaukee. This repository serves as a record of my hands-on learning and academic work in the field of cybersecurity and digital forensics.
---
## About the Course
This course covers the principles and practices of digital forensics, including the acquisition, preservation, and analysis of digital evidence. Coursework involves:
- **Hands-on labs** using **Kali Linux** via **Oracle VirtualBox**
- **Review questions** based on assigned textbook readings
- Practical exposure to forensic tools and investigative methodologies

| [Homework 7](./Homeworks/Homework7.pdf) | *Chapter 6 review questions covering digital forensics tool classifications, acquisition types, the five core tool functions (validation, extraction, reconstruction, reporting, and acquisition), write-blocking devices, ISO 17025 testing standards, and hash-based evidence verification. ## Tools & Technologies
- **Kali Linux** — Primary OS used for forensic labs and exercises
- **Oracle VirtualBox** — Virtualization platform used to run Kali Linux
- **Autopsy / Sleuth Kit** — Digital forensics analysis tools
- **Guymager** - Linux-based tool used to create disk images or clone disks for forensic analysis
